# Secure By Design: Product Security Capability & Maturity Assessment Framework

Welcome! This repository contains the Product Security Capability and Maturity Framework used to assess and improve secure-by-design practices across the medical device and software lifecycle. 

## What Is This?

This framework provides a structured, practical approach to evaluate and mature your organization’s security capabilities – from wild-west ad hoc chaos, through repeatable and defined processes, up to a state where you’re actually sleeping well at night.

It covers the following domains:
- **Secure Design:** Threat modeling, secure architecture, and design controls
- **Secure Development:** Coding standards, code review, and integration of security tools
- **Security Testing:** Static/dynamic analysis, penetration testing, and control validation
- **Risk Management:** Risk assessment, mitigation, and continuous monitoring
- **Privacy & Data Protection:** Encryption, access controls, and data minimization
- **Lifecycle Management:** Patch management, end-of-life, and ongoing security

Each domain is broken down into specific functions, activities, and best practices, with maturity levels from “Ad Hoc” (Level 1) to “Optimized” (Level 5). 

## Why Should You Care?

Let’s face it, “checkbox security” doesn’t actually secure anything. This framework is designed to help you move from reactive to proactive, enabling compliance with regulatory expectations, and actually making your products and patients safer.

## How Do I Use This?

1. **Read the [Maturity Framework.pdf](Maturity%20Framework.pdf)** for all the details, scoring criteria, and guidance.
2. Use the included assessment templates to score your current practices.
3. Identify gaps and areas for improvement.
4. Rinse, repeat, and brag at your next audit.
