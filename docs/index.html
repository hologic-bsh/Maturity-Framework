Secure By Design: Product Security Capability & Maturity Assessment Framework

Welcome to the open source framework for assessing and maturing security practices across medical device and software development. Why settle for “compliant enough” when you can actually be secure?

Framework Domains

  • Secure Design: Threat modeling, architecture, and requirements baked in from the start
  • Secure Development: Coding standards, reviews, automation, and actual secure code (imagine!)
  • Security Testing: Static/dynamic analysis, pen testing, and control validation
  • Risk Management: Proactive risk ID, mitigation, and monitoring
  • Privacy & Data Protection: Encryption, access, and privacy by design
  • Lifecycle Management: Patch management, end-of-life planning, and continuous improvement

Getting Started

  1. Download and read the Maturity Framework.pdf.
  2. Assess your current maturity using the provided criteria.
  3. Make a plan. Get better. Repeat.
